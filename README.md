# Gene2Protein Analysis of THRA

## Project Overview

This project performs Gene → Transcript → Protein analysis for the human THRA gene (ENSG00000126351) using Ensembl annotations and Bioconductor packages in R.

The project demonstrates how a single gene can produce multiple transcript isoforms and protein products through alternative splicing.

---

## Gene Information

- Gene Name: THRA
- Ensembl Gene ID: ENSG00000126351
- Gene Type: protein_coding
- Chromosome: 17

---

## Analysis Performed

- Gene information extraction
- Transcript extraction
- Protein extraction
- Canonical transcript identification
- Transcript → Protein mapping
- TSV file generation

---

## Biological Significance

THRA (Thyroid Hormone Receptor Alpha) is involved in thyroid hormone signaling and regulation of gene expression.

The analysis revealed multiple transcript and protein isoforms generated through alternative splicing, demonstrating transcript diversity in human genes.
